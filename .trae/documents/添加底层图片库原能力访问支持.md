## 实现计划

### 问题分析
用户需要通过ImageLoader实现Glide的同步加载Bitmap能力，具体场景是：
```kotlin
Glide.with(this@AudioPlayService)
     .asBitmap()
     .load(AudioPlay.book?.getDisplayCover())
     .submit()
     .get()
```

当前ILoaderStrategy接口仅支持异步加载图片到ImageView，缺少同步加载Bitmap和指定返回类型的能力。

### 解决方案
1. **扩展ILoaderStrategy接口**：添加同步加载Bitmap的方法
2. **扩展ImageOptions**：添加支持指定返回类型的配置
3. **修改GlideStrategy**：实现同步加载Bitmap的方法
4. **增强ImageLoader类**：添加静态方法用于同步加载Bitmap
5. **保持向后兼容**：确保现有API不受影响

### 具体修改步骤

#### 1. 修改ILoaderStrategy接口
- 添加`loadBitmapSync`方法，支持同步加载Bitmap
- 方法返回Bitmap?，支持空返回
- 接收Context和ImageOptions参数

#### 2. 修改ImageOptions类
- 添加`returnType`字段，用于指定返回类型（如Bitmap、Drawable等）
- 添加枚举类型`ReturnType`，支持不同返回类型
- 在Builder中添加`asBitmap`便捷方法

#### 3. 修改GlideStrategy类
- 实现`loadBitmapSync`方法
- 支持Glide的`asBitmap()`和`submit().get()`调用
- 处理异常情况，确保方法安全

#### 4. 修改ImageLoader类
- 添加静态方法`loadBitmapSync`，支持同步加载Bitmap
- 提供便捷方法`asBitmap()`用于指定返回类型
- 支持Java和Kotlin调用

### 预期效果

**使用示例（Kotlin）**：
```kotlin
// 同步加载Bitmap
val bitmap = ImageLoader.loadBitmapSync(context, url) {
    asBitmap() // 指定返回类型为Bitmap
    resize(200, 200) // 可选：设置尺寸
}
```

**使用示例（Java）**：
```java
// 同步加载Bitmap
Bitmap bitmap = ImageLoader.with(context)
    .load(url)
    .asBitmap()
    .resize(200, 200)
    .submitSync();
```

### 实现细节

1. **ILoaderStrategy扩展**：
   - 添加`fun loadBitmapSync(context: Context, options: ImageOptions): Bitmap?`方法
   - 方法返回Bitmap?，支持空返回
   - 处理可能的异常

2. **ImageOptions扩展**：
   - 添加`enum class ReturnType`枚举，包含BITMAP、DRAWABLE等
   - 添加`returnType`字段，默认值为DRAWABLE
   - 在Builder中添加`asBitmap()`便捷方法

3. **GlideStrategy实现**：
   - 在`loadBitmapSync`方法中，使用Glide的`asBitmap()`和`submit().get()`
   - 处理InterruptedException和ExecutionException
   - 确保方法安全

4. **ImageLoader增强**：
   - 添加静态方法`loadBitmapSync`
   - 添加JavaBuilder支持
   - 提供便捷的链式调用
